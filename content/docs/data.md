Once a day our server builds a snapshot of public advisories and publishes it at `https://data.shipward.dev/v1/`.
It receives nothing from you: the files are the same for everyone.

## Sources

We pass on only sources whose terms allow it, filtered to package ecosystems and shortened. Each is named here, in
the snapshot's index and in every `shipward scan`.

| Source | Licence |
|---|---|
| [GitHub Advisory Database](https://github.com/advisories) | CC-BY-4.0 |
| [Go Vulnerability Database](https://pkg.go.dev/vuln/) | CC-BY-4.0 |
| [PyPA Advisory Database](https://github.com/pypa/advisory-database) | CC-BY-4.0 |
| [RustSec Advisory Database](https://rustsec.org) | CC0-1.0 (parts from GitHub: CC-BY-4.0) |
| [Drupal Security Advisories](https://www.drupal.org/security) | MIT |
| [OSS-Fuzz](https://github.com/google/oss-fuzz-vulns) | CC-BY-4.0 |
| [CISA Known Exploited Vulnerabilities Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) | CC0-1.0 |

The advisories come from OSV.dev's collection. Records from sources whose terms do not allow commercial reuse are
left out, and so are records of malicious packages.

`shipward` fetches two feeds from their publishers itself, and they are not in the snapshot: the
[ENISA EU Vulnerability Database](https://euvd.enisa.europa.eu) and
[EPSS scores by FIRST.org](https://www.first.org/epss), generated by Empirical Security.

## The snapshot

| File | What |
|---|---|
| `v1/index.json` | The index: each file's SHA-256 and size, the sources and their licences, the time it was made, and an Ed25519 signature over all of it |
| `v1/<run>/osv-<ecosystem>.json.gz` | The advisories of one ecosystem (npm, NuGet, Packagist, Go, PyPI, Maven, crates.io, RubyGems) |
| `v1/<run>/exploited.json.gz` | CISA's catalog of known exploited vulnerabilities |

Each run writes a new folder and replaces the index last, so a reader never sees an index that names missing files.

`shipward` accepts an index only with a valid signature from a key built into it, then checks each file's SHA-256 against
the index. The public key:
